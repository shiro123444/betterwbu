# BetterWBU

武汉商学院报销系统的 Chrome 扩展，当前版本 **0.13.5**。

## 0.13.5：窄屏导航展开状态

窄屏下导航收起时仅显示图标；展开后同时显示图标和文字。沿用学校原生展开/收起状态与路由行为。

## 0.13.4：窄屏侧栏与表格边界

窄窗口或页面缩放时，左侧导航收成图标轨道，隐藏被挤成竖排的菜单文字；保留原菜单节点和路由。表格宽度继续限制在各自卡片内，只有表格内部横向滚动，避免带宽表撑宽整张页面。

## 0.13.3：容器溢出与左侧导航

费用明细标签、工具按钮和表格区域现在都受表单容器宽度约束，窄窗口中操作按钮可换行，宽表在自身区域滚动。左侧导航沿用学校菜单和原始跳转，仅更新分组卡片、选中态和线框图标；窄栏中图标仍可见，展开时显示完整菜单。

## 0.13.2：表格字段宽度修复

基本信息的双列布局仅作用于字段组，不再作用于表格内的单个 `ant-row.ant-form-item`。原先 156px 的日期区域会被错误拆成两列，输入仅剩 66px；现恢复整格宽度。费用、预算、收付款等表格保留原输入节点及值，金额输入字号与其他字段统一。宽表继续在表格内部滚动，不向页面外溢出。

已在学校当前页面只更新样式，验证日期完整显示、输入值及禁用状态保持不变。新增合成回归页 `tests/browser/react/table-layout.html`，按真实嵌套结构复现，检查 1440、900、600、360px 窗口及只读状态。此项验证不包含生产保存或提交。

## 0.13.1：识别超时与结果提示

发票夹管理页跟踪已观察到的识别任务。等待超过两分钟显示“等待超时”，停止该卡片的等待动画；在没有勾选、编辑或上传时最多每三十秒执行一次原生列表查询，并提供“重新查询”入口。有对应票据才显示“已识别”；任务消失而没有对应票据时显示“结果未确认”。网络查询失败不会被当作任务完成。

只调用已确认的只读列表接口，不重新上传、不重新识别、不处理重复票、不保存或提交报销单。关闭增强会恢复原等待文字和动画。识别状态不等于票审或稽核通过；修复不会恢复后台已经缺失的结果，也不能追溯安装前未观察到的任务。

## 0.13：Base UI 交互组件

插件新增交互统一使用 Base UI 1.9.0，移除 Radix 下拉菜单依赖。信息管理的开户行、模板选项、表单模板入口使用可搜索 Combobox；收付款中的已保存收款人使用 Popover 与 Combobox，仍通过原桥接校验整条回填，不替换原 Vue 输入框。

侧栏使用 Base UI Dialog，桌面保留正文，1100px 以下约束面板焦点。覆盖模板和清除资料使用统一确认弹窗。插件自有详情使用统一 Dialog 外壳；学校原生费用详情保留字段、事件及校验，用相同字号、间距和圆角优化外观。合成预览中的住宿详情直接运行 Base UI 外壳，不能据此声称学校原生详情已完全替换。

资料、模板和设置保存成功后显示短提示；原生暂存反馈仅在系统已显示明确成功消息时转成 Toast，原错误消息继续保留。弹窗、下拉、侧栏和提示使用 140–180ms 的可中断过渡，不等待动画再保存，不对每个表单区块重复播放入场动画。关闭“动态效果”或系统设置减少动态效果时停用新增动画。

组件源码为 `src/ui-runtime.jsx`，样式为 `src/components.css`。Base UI、React 及样式随扩展打包，无远程 CDN、无新增浏览器权限。验证覆盖异步结果过期、键盘选择、完整资料保存、手填银行、失败反馈、确认取消、原输入节点保留，以及回填后不重复打开选择器。

## 0.12.4：章节导航滚动修复

解除原生表单外壳和 `bill-box` 的固定高度、隐藏溢出限制，统一由外层页面滚动。章节导航保持可见，跳到费用或收付款后可正常返回上方。修复仅作用于表单外壳，不改变单据字段或票据归属。

真实新草稿验证了基本及项目信息暂存成功。原已提交单据的票据在新单选择器中不可选，因此尚未完成保险、住宿关联的生产保存验收；不得把这个结果写作关联保存通过。

## 0.12.3：开户行搜索与焦点细节

信息管理内的开户行搜索支持方向键、Home/End 和回车选择，输入框保留焦点并关联当前选中结果。Esc 先收起查询结果，防止待返回的查询重新打开列表；再次 Esc 可关闭信息管理。取消收款资料或模板编辑、保存收款资料后，焦点回到对应新增按钮。沿用现有组件、银行字典核验和本地存储。

## 0.12.2：两侧菜单与信息管理

统一学校左侧菜单、收款资料、基本模板、设置页的字号、留白和 8px 圆角，保留学校菜单节点、图标和路由。信息管理在各页面常驻；桌面打开后正文与底部操作区避让，1100px 以下单独展开，支持 Escape 关闭、键盘切换页签和焦点恢复。资料及模板编辑时收起旧列表，减少重复内容；关闭按钮只显示一个图标。界面主题源文件为 `src/manager.css`，构建时生成供信息管理读取的 `extension/manager-theme.js`。

合成预览加载实际发布的信息管理组件，提供内存中的示例收款资料、模拟银行字典及基本模板，可以体验新增、编辑、保存与跨页面打开。该预览不连接学校后台、不保存真实账号；左侧导航用原菜单结构演示表单与列表切换。

## 0.12.1：复用现有图标

保留原页面学校 logo；合成预览也采用同一校方公开标识。费用分类重新显示已有图标和原分类色，图标缩为 28px，统一 8px 圆角；复用现有图标节点及点击事件，不影响金额或分类选择。

## 0.12：React 整页布局

保留学校顶部导航、原表单字段及业务事件，用 React 统一整页章节导航、栏目标题、金额展示和明细操作。字段改为标签在上方、正文两列的布局，按实际内容宽度变为一列。取消右侧稽核区对正文的挤压；宽表只在自己的容器中滚动。控件、卡片和弹窗统一使用 8px 圆角、16px 输入文字和同一组蓝灰色变量。

行内保留直接可见的“详情”；新增、复制此行和删除此行收进键盘可操作的“更多”菜单。这里只路由到原生事件，工具栏“复制末行”仍保持原来的含义。只读页面不新增编辑权限。原暂存/提交按钮和模板、资料的存储及回填逻辑继续保留。

React 通过 Portal 接入已有 DOM，负责表单布局和统一控件；原 Vue 字段、校验与票据 iframe 继续工作。不会克隆或搬动字段/iframe，不会独立创建另一份财务草稿。新布局启用时停用旧排版规则；关闭视觉优化时恢复原控件和标题。实现依据 [React 在现有项目中使用组件](https://react.dev/learn/add-react-to-an-existing-project) 和 [Portal 集成外部 DOM](https://react.dev/reference/react-dom/createPortal)。

当前验证：**188 项测试通过**，包括编译后的 React 按钮事件、重复初始化、页面根节点替换、关闭恢复、输入保留、iframe 节点保留，以及实际信息管理的编辑保存、页签键盘操作、窄屏焦点约束和跨页面记录保留。另覆盖开户行键盘选择、Esc 撤销待查询、取消及保存后的焦点恢复。合成浏览器预览检查了宽窄窗口、侧栏避让、窄窗口详情、只读状态和行内菜单。票据生成另验证原生关联、保险分摊、住宿凭证、人员编号一致性、失败回滚和收付款不变。窄宽度检查覆盖缩放后可用空间变小的布局压力，尚未实测用户 Chrome 的各个缩放档位。尚未完成 0.13.0 在学校真实页面上的新版界面回归或生产保存/提交验收。

## 安装

1. 下载或克隆本仓库。
2. 打开 Chrome 的 `chrome://extensions/`，启用开发者模式。
3. 点击“加载已解压的扩展程序”，选择 `development/reimbursement-enhancer/extension`，该目录直接包含 `manifest.json`。
4. 打开报销系统，通过扩展弹窗检查页面连接和版本。更新前先保存正在填写的草稿，再重载扩展和页面。

## 功能

票据生成现同时写入原生费用行关联，支持明确按人员分摊、保险按人员合并、住宿凭证以零使用金额挂到具名费用行。预览要求每张发票分摊金额守恒，追加检查已有使用金额；替换、撤销及失败回滚同时处理关联与金额。详见 [票据关联使用与验证](development/reimbursement-enhancer/scripts/票据关联使用与验证.md)。已提交单据不会自动修改；学校后台真实保存接受和稽核须在新草稿中验收。

- 统一表单、发票夹和报销详情布局，修复重复按钮和横向溢出。
- 发票夹确认时显示请求与预览更新状态，阻止重复确认。
- 从有效票据生成费用明细，支持分类、去重、更新所选分类和撤销；支付截图与辅助材料不参与发票合计。
- 根据明确的住宿起止日期预填差旅时间，核对人员、地区和适用条件后计算补贴。
- 保存收款资料和基础模板，支持银行字典及手填开户行。
- 加载反馈依据原生请求状态显示，支持减少动态效果；不会自动重复提交。

费用和补贴须由使用者核对。学校后台的稽核规则、审批结论及有效发票金额统计由原系统决定；插件的分类结果不代表后台稽核已通过。界面默认精简黄色提醒，保留阻断错误和原生稽核报告入口。

## 开发与验证

维护代码位于 `development/reimbursement-enhancer/extension`，测试位于同级 `tests`。

开发使用 Node.js 22.22.2、24.15.0 或相应更新兼容版本。插件已附带编译产物，直接安装不需要 Node.js；修改源码或运行完整测试需安装锁定依赖：

```bash
cd development/reimbursement-enhancer
npm ci
npm run build
npm test
```

测试覆盖费用金额与重复生成、补贴、数据过期防护、MAIN/ISOLATED 执行环境、收款资料、确认反馈和布局恢复。浏览器演示使用合成数据；本地测试通过不代表学校系统的保存、提交、审批全流程已验收。

React 源码在 `src`，打包脚本在 `scripts/build.mjs`，生成 `extension/workspace.js` 及第三方许可证说明。所有依赖随插件打包，不加载远程 React/CDN。

构建、测试通过后执行 `python scripts/package.py`，得到 `dist/betterwbu-0.13.3-source.zip`，包含编译后的可安装扩展、React 源码、锁文件、测试和 SHA-256 校验清单。

可运行以下命令查看合成预览：

```bash
python tests/browser/react/serve.py
```

打开 `http://127.0.0.1:8767/tests/browser/react/index.html`；只读示例为同一地址加 `?readonly=1`。该预览没有连接学校系统，按钮仅调用合成原生事件，不提交财务数据。

仓库包含维护中的插件源码、合成测试和预览所需的公开校方标识/界面图标，不包含个人票据、财务诊断、截图、登录信息、历史安装副本或采集的学校前端资源。
